# Model Outputs

This directory stores visual and quantitative inspection outputs generated by running `notebooks/Concrete_Crack_Detection.ipynb` or the deployed Streamlit web application (`app.py`).

---

## 📊 Output Structure

Each full inspection run produces both visual diagnostics and quantitative structural measurements:

1. **Classification Probabilities (`custom_cnn_crack_model.pth`):**
   * **Non-Cracked Probability:** Softmax probability score for an intact surface.
   * **Cracked Probability:** Softmax probability score indicating structural crack presence.

2. **Segmentation Visuals (`best_unet_crack_model.pth`):**
   * **U-Net Probability Map:** Continuous pixel-level confidence heatmap of detected crack regions.
   * **Crack Segmentation Mask:** Thresholded binary mask isolating foreground crack pixels from background textures.
   * **Cracks Highlighted in Red:** Original surface image overlaid with the segmented crack mask.

3. **Crack Measurements & Severity:**
   * **Crack Area (`pixels`):** Total foreground segmented pixel count.
   * **Crack Length (`pixels`):** Skeletonized medial-axis centerline length.
   * **Average Crack Width (`pixels`):** Mean cross-sectional width across the segmented crack.
   * **Maximum Crack Width (`pixels`):** Peak cross-sectional width across the segmented crack.
   * **Crack Severity:** Automated severity classification (`Low`, `Medium`, or `High Severity`).
