# Model Outputs

This directory stores visual and quantitative inspection reports generated by running `notebooks/Concrete_Crack_Detection.ipynb` via the `analyze_concrete_image_safeguarded()` pipeline.

---

##  Output Structure

Each generated diagnostic report consists of two components:

1. **Quantitative Inspection Summary:**
   * **Target Surface File:** Name of the evaluated image file.
   * **Detection Status & Confidence:** `CRACKED` (via direct classification or `OVERRIDDEN BY SEGMENTATION` safeguard) along with the confidence percentage.
   * **Geometric Metrics:**
     * **Crack Area (`px`):** Total foreground segmented pixel count.
     * **Crack Length (`px`):** Skeletonized medial-axis centerline length.
     * **Average Width (`px`):** Mean cross-sectional width across the segmented crack.
     * **Maximum Width (`px`):** Peak cross-sectional width across the segmented crack.
   * **Estimated Severity:** Automated severity classification (`LOW`, `MEDIUM`, or `HIGH`).

2. **3-Panel Visual Diagnostic:**
   * **Left Panel:** Original input surface image.
   * **Center Panel:** Predicted binary segmentation mask highlighting detected crack pixels.
   * **Right Panel:** Localization and skeletonized centerline overlay color-coded by severity level.
